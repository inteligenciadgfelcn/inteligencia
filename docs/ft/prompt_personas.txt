Prompt para generar caso Personas:

Proceso:

Inicio

1. Ingreso de información

1.1. El usuario ingresa un documento de identidad.

2. Búsqueda de persona existente

Realizar una búsqueda en la base de datos:

Base de datos: felcn_personas
Tabla: public.personas
Campo de búsqueda: documento

Evaluar resultado:

2.1. Persona encontrada

Si existe una persona con el documento ingresado:

Obtener y devolver los siguientes datos:

documento
nombres
paterno
materno
esposo
sexo
ocupacion
dir1

Luego continuar con la validación del conductor.

2.1.1. Buscar conductor existente

Realizar una búsqueda en la base de datos:

Base de datos: felcn_s2i
Tabla: public.conductor
Campo de búsqueda:
numero_documento
Valor utilizado: documento ingresado inicialmente en el punto 1

Evaluar resultado:

2.1.1.1. Conductor encontrado

Si existe un registro en public.conductor:

Retornar el registro completo del conductor.
Finalizar proceso.
2.1.1.2. Conductor no encontrado

Si no existe un registro en public.conductor:

Permitir el registro de un nuevo conductor utilizando la información obtenida desde felcn_personas.

Mapeo de datos para crear conductor:

Campo conductor	Valor origen
numero_documento	documento ingresado
nombres	nombres de persona
paterno	paterno de persona
materno	materno de persona
esposo	esposo de persona
idPais	70
sexo	sexo de persona
ocupacion	ocupacion de persona
direccion	dir1 de persona

Después del registro:

Retornar conductor creado.
Finalizar proceso.
2.2. Persona no encontrada

Si no existe una persona en:

Base de datos: felcn_personas
Tabla: public.personas

Realizar registro de una nueva persona.

Datos necesarios para crear persona:

documento
nombres
paterno
materno
esposo
sexo
ocupacion
dir1

Después de registrar correctamente la persona:

Continuar con el flujo:

2.1.1 Buscar conductor existente

Es decir:

Buscar en BD felcn_s2i
Tabla public.conductor
Campo numero_documento
Usando el documento ingresado inicialmente.
Reglas del flujo:
La primera fuente de información es siempre felcn_personas.public.personas.
Si la persona existe, reutilizar sus datos.
Si no existe, crearla antes de continuar.
La validación del conductor siempre se realiza después de obtener los datos de persona.
La creación de conductor reutiliza la información de persona.
idPais para conductor debe asignarse siempre con valor 70.
Resultado esperado del diagrama:

Debe mostrar:

Inicio
Entrada de documento
Consulta a felcn_personas.public.personas
Decisión: persona existe / no existe
Registro de persona si corresponde
Consulta a felcn_s2i.public.conductor
Decisión: conductor existe / no existe
Retorno de datos si existe
Registro de conductor si no existe
Fin del proceso
